# Attachments, proofing and file versions

## Purpose
Keep files on an item, review them visually and track versions.

## Steps
- **Attach:** item → **Attachments** → **Choose file** or drop a file (“Or drop a file here”). Choose one file at a time. **Add link** (**Link address**) attaches a link. **Remove attachment** deletes it.
- **New version:** **Upload new version** on an attachment. Labels show **v1, v2…**, with **current** on the latest; **Version history** lists them.
- **Compare:** **Compare versions** → pick **Left** and **Right** (two different versions) to see them side by side (“Version N, page M”).
- **Proof:** **Proof** opens a preview. Click the image to pin a note: type in **Pin note**, then **Pin comment**. Page through with **Previous page** / **Next page**. **Pinned comments** can be **Resolve**d, **Reopen**ed or **Delete**d.
- **File reviews:** an approval can pin a file version (see [Approvals](approvals.md)). **More → File reviews** (“Files to review”) lists files waiting for you.

## Permissions
Attaching needs *Attach files* (Limited and above). Proof comments need comment access; otherwise you can read them (“commenting needs comment access”).

## Limitations
Upload size limit comes from the server (shown in the comment box). Form uploads accept PDF, PNG, JPEG, GIF, WebP, text or ZIP. If no preview exists you see “No preview is available… Download it” or “The preview could not be created”. Cloud-storage attachments (Pydio, MinIO) are not yet available as a user feature.
