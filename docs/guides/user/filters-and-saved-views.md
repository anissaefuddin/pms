# Filters and saved views

## Purpose
Narrow what a view shows and keep useful setups as named views.

## Steps
- **Filter items:** the **Filter items** box matches text; **Filter by type** (*All types* or one type); **Preset** — **All tasks**, **All active**, **My active**; **Filter by field** (choose a custom field and a **Field value**, then **Apply**; checkboxes use **Checked** / **Unchecked**). **Clear filters** resets.
- **Sort:** **Sort** by Name, Status, Finish date, Start date, Priority, Predecessors, a custom field (**Field: {name}**) or **Manual order**.
- **Group** (Board): **None** or **Assignee**.
- **Saved views:** create a named view with **Add view** (see [Views](views.md#managing-views)), choose **Public** (everyone with access) or **Personal** (only you), then **Set as default**, **Duplicate as personal** etc. Visible columns are saved with each view (“Saved with this view”).
- **Share a view:** use **Copy link** in the item actions for a link to the Space/item.

## Permissions
Personal views are private. Public views can be changed by people who can edit the container.

## Limitations
Whether filter, sort and group choices are stored in the saved view, as opposed to only the columns, could not be confirmed from the UI strings. Treat filters as session settings unless you see them restored. Search-result filters are in [Search](search-and-navigation.md).
