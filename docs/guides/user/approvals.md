# Approvals

## Purpose
Ask people to formally approve or reject an item (optionally one file version).

## Request an approval
1. Open an item → **Approvals** → **Add approval**.
2. Fill **Description**, **Due date**, **Approvers** (at least one, else “Choose at least one approver”), **Approval policy** (**All approvers** or **Any approver**), and optionally **File to review (optional)** (*No file (whole item)* by default).
3. **Save approval**. The counter shows e.g. “1/2 approved”; status is **Pending**, **Approved** or **Rejected**.
- **Edit approval**, **Delete approval** (removes all decisions), **Reassign approvers** change an existing request. **Decision history** lists events (requested, removed, decided, withdrawn).

## Decide
Approvers get an Inbox notification “asked you to approve {title}”. Open the item, optionally add a **Comment (optional)**, and choose **Approve** or **Reject**. Reminders and overdue escalations are also sent to the Inbox.

## From forms
A form can request approval for each new item ([Forms and blueprints](forms-and-blueprints.md)).

## Permissions
Only listed approvers decide. Creating/editing approvals needs edit rights on the item.

## Limitations
The approval is pinned to the item version at request time (“item version N”).
