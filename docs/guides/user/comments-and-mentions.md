# Comments and mentions

## Purpose
Discuss an item and notify people.

## Steps
1. Open an item; in **Comments** type in the **Comment** box.
2. Mention people or groups with `@` (search box: “Find a user or group to mention”); choose **Mention followers** to mention everyone following the item. Followers appear under **Followers**.
3. Attach files (**Choose file**; max size shown as “Maximum file size: N MB”).
4. Press **Post comment**. Your profile sets the send shortcut: *Ctrl/Cmd + Enter* or *Enter* (Profile → **Send comment shortcut**).
5. **Edit comment** / **Delete comment** act on a comment; **More comments** / **Latest comments** page through the thread.

## Effects
A mention creates an Inbox notification “{actor} mentioned you in {title}” and, if enabled in your profile, an email ([Notifications](notifications-and-email.md)). **Comments themselves are never emailed.**

## Permissions
Commenting needs the *Comment* capability (Limited role and above). Read-only users cannot post.

## Limitations
Rich formatting inside comments and exact mention-group resolution rules were not confirmed from the code.
