# Templates

## Purpose
Start from ready-made structure instead of from nothing.

## Space templates
**New Space** → **Start from** → choose a template (default **Blank Space**). The dialog says what it brings: projects, tasks, extra views, forms and custom fields. Name it and choose **Create Space**; share it afterwards.

## Blueprints (item templates)
Save any item and its contents with **Save as blueprint** and reuse via **Start from blueprint** when creating items. Details in [Forms and blueprints](forms-and-blueprints.md#blueprints).

## Report templates
**New report** → **Start from**: Blank report, Active tasks by assignee, Weekly project status, Overdue tasks, Tasks due this month, Unassigned tasks, Time spent this month, Utilization this month. See [Reports and dashboards](reports-and-dashboards.md).

## Permissions / limitations
The list of Space templates is defined by the server; no UI to author Space templates was found in the code.
