# Reports and dashboards

## Reports
Open **More → Reports**.
1. **New report**: **Name**, **Location** (*My reports (private)* or a Space), **Who can see it** (**Only me** / **Everyone in the Space**), **Start from** a template or **Blank report** → **Create report**.
2. Editor: **Based on** Tasks, Projects or Time entries; choose **Spaces** (none = all you can see) and optional **Projects and Folders**; **Layout** Table or Column chart; **Metric** (Number of items, Effort, Time, Billable time, Actual cost, Utilization, Sum/Average of a number field, Completion %), **Group by**, **Break by**; **Filters** (status group, importance, assigned to me, unassigned, followed, overdue, due dates, effort, entry dates, billing, logged by me).
3. **Run report**, **Save report**, **Export CSV**.
4. **Email subscription**: **Day**, **Hour**, **Time zone** → **Subscribe** (or **Unsubscribe**); emailed with data you may see. Turn off in Profile → Email notifications (“Scheduled report emails”).

## Dashboards
Open **More → Dashboards**. Switch scope (**My dashboards (private)** or a Space), **Create dashboard**, or **Create analytics board**.
- **Add widget** → pick a type: Task list, Indicator, Completion progress, Pie (Classic/Donut/Ring), Column, Bar, Line, Area, Burndown, Table, Pivot table; set **Widget name**, **Shows**, **Show legend**/**Show labels**, **Save widget**.
- Widget menu: **Edit**, **Delete**, **Move earlier/later**; **Show data as a table**. **Layout**: *Side by side* or *One above the other*.
- Dashboard menu: **Rename**, **Duplicate**, **Move**, **Delete**.
- **Public link**: **Turn on**, **Link expires after**, optional **Password**, **Replace link**, **Turn off**. Money widgets are hidden for public viewers; the link is shown once.

## Permissions
Report/dashboard owners change sharing. “You can run this report but not change it” = read only.

## Limitations
Very large sources return “The data source is too large”; pick fewer Spaces or add filters.
