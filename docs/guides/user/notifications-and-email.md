# Notifications and email

## Inbox
Open **Inbox** (badge shows unread count). Events: mention, assignment, status change, comment, shared with you, approval requested/decided/reminder/overdue. Controls: **Unread only**, **Mark all as read**, **Archive** per item, **Archive all**, **Load more notifications**. “You're all caught up” means empty.

## Stream
**Stream** (enable in Profile → Sidebar) shows activity with filter **Everything / Followed / Assigned to me / My conversations** and **Hide auto updates**.

## Email
Profile → **Email notifications**: choose emails for *Someone mentions me*, *A task is assigned to me*, *Something is shared with me*, *Status changes and approvals on tasks I follow*, *Scheduled report emails*. Everything still appears in the Inbox. Comments are never emailed. Public form submitters get confirmation/status emails ([Forms](forms-and-blueprints.md)).

## Limitations
Email needs SMTP configured by an administrator. A live indicator (**Live** / **Connecting…**) shows real-time updates.
