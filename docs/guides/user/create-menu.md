# The “+” menu of a Space

## Purpose
Decide which item types people are offered when creating items in a Space.

## Steps
1. Open the Space and choose **“+” menu** (““+” menu of this Space”).
2. Under **Item types in the menu** tick the types to offer.
3. **Save menu**.

## Effects
Only existing choices change: existing items are untouched and the type stays available elsewhere. A fixed parent (e.g. **Add subitem**) or a Board's task-only add ignores the menu. See [Items](items.md#create-an-item).

## Permissions
Requires manage rights on the Space.

## Limitations
This menu selects types only. Renaming entries or choosing icons (PRD SPC-14) is **not yet available** in the code. If the menu cannot load you see “The menu could not be loaded”.
