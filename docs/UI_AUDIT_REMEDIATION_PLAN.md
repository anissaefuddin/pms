# Rencana remediasi audit UI PMS

Baseline [Audit Visual PMS](UI_AUDIT_REPORT.md) 64/100 pada `0872b69`. Urutan Batch A → B → C → D mengikuti dependensi layout. Pemeriksaan Gantt pada Batch B dapat berjalan independen setelah UI-01 masuk tahap retest. Tiap batch ditutup dengan pemeriksaan empat viewport dan bukti before/after terpisah dari baseline audit.

| Batch | Defect | Validasi source dan target | Kriteria penerimaan | Risiko regresi |
|---|---|---|---|---|
| A | UI-01 P1 | `routes/_app.tsx` dan `sidebar.tsx` selalu menyisihkan sidebar desktop. `topbar.tsx`, dialog bersama dan header Space terdampak saat lebar menyempit. Table dan Board sudah punya region scroll. | Pada 390 dan 768, navigasi tertutup saat masuk, dapat dibuka dari topbar, ditutup dengan Escape atau pemilihan tujuan, dan fokus kembali ke pemicu. Home, Space Table/Board dan Task panjang tidak meluapkan dokumen. 1280/1440 mempertahankan sidebar, tree dan preferensi collapse. | Fokus portal, klik route saat dialog aktif, resize ketika drawer terbuka, nested menu, ikon topbar dan duplikasi landmark. |
| B | UI-02 P1 | `routes/_app/settings.tsx` memakai kolom 15rem dan padding 32px tanpa breakpoint. `settings/account.tsx` menambah kolom label 12rem. Mulai setelah A. | Enam halaman Settings dapat dioperasikan di 390/768 tanpa scroll dokumen. Tautan bagian aktif dan fokus keyboard jelas. Desktop mempertahankan navigasi dan layout dua kolom. | Lebar form, label panjang, policy table dan fokus link. |
| B | UI-03 P1 | `components/item-gantt.tsx` mengintegrasikan SVAR. Runtime `@svar-ui/react-grid` menghasilkan `aria-expanded` pada row grid dan indeks dapat mulai dari nol. | Dua aturan axe dari audit bersih pada 390/1440, terang dan gelap. Verifikasi navigasi, ekspansi dan pembacaan urutan baris. | Upgrade atau perubahan adapter dapat mengganggu drag, scroll, grouping dan keyboard. |
| C | UI-04 P2 | `components/item-calendar.tsx` sudah menyediakan `overflow-x-auto`. Audit melihat 903px pada 768. Konfirmasi ancestor yang memperlebar dokumen setelah A. | Seluruh aksi bulan terlihat pada 390/768. Dokumen tidak bergulir horizontal. Tujuh kolom tetap dapat dijangkau melalui scroll lokal. | Fokus grid, drag antar tanggal dan desktop dengan banyak kartu. |
| C | UI-05 P2 | `routes/_app/forms.tsx` merender URL penuh dengan `break-all` dalam sel Link. Bergantung pada lebar shell Batch A. | URL panjang memakai label ringkas atau elipsis pada 768. Salin via keyboard menghasilkan URL lengkap. Tabel tetap mudah dipindai pada empat viewport. | Clipboard, link publik/internal dan lebar kolom desktop. |
| C | UI-06 P2 | `routes/__root.tsx` dan `main.tsx` tidak menetapkan tampilan not-found global. | URL tak dikenal pada empat viewport memiliki heading, deskripsi dan aksi kembali yang dapat ditab. Uji sesi anonim dan terautentikasi. | Redirect auth, fallback router dan 404 khusus fitur. |
| D | UI-07 P3 | Route Space merender empty overview dan tetap memasang `ViewWorkspace`; `item-table.tsx` menampilkan empty hasil. | Satu pesan untuk Space baru dan satu pesan berbeda untuk filter tanpa hasil, dengan tindakan yang tepat dan tanpa false empty saat memuat. | Preset, izin create, dan view non-Table. |
| D | UI-08 P3 | Home, Settings dan Forms/Timesheets memakai utilitas 30/20/24px. Draft Design System menyebut 20/22px menurut density. | Selaraskan heading dengan peran setara setelah konfirmasi pengecualian Home. Uji ukuran computed di density compact dan comfortable. | Perubahan hierarki massal dan pemenggalan judul di mobile. |

UI-01 adalah satu-satunya perubahan implementasi putaran ini. Settings, Calendar, Gantt dan komponen lain dalam tabel tetap mengikuti retest batch masing-masing.
