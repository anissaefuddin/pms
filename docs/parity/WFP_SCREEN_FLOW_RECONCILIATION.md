# Rekonsiliasi WFP dengan alur layar

S7.2.1 · Pembacaan dokumen alur dan referensi resmi untuk 106 baris. Status **Alur tersedia** berarti dokumen layar membahas kemampuan utama. **Parsial** berarti hanya titik masuk atau sebagian perilaku tercatat. **Gap** berarti belum ada alur sepadan di dokumen layar. Status ini mengukur bukti layar dan terpisah dari ketersediaan paket maupun hasil UAT PMS.
